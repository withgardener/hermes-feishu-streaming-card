# V4.1.0 Native Policy And Runtime Safety Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development or superpowers:executing-plans. Every
> production behavior follows RED/GREEN/refactor and is integrated only from a
> clean, reviewed task commit.

**Goal:** Release V4.1.0 with per-chat native delivery, lossless table overflow,
authenticated runtime-integrity monitoring, and explicit safe sidecar service
management.

**Architecture:** Keep the existing sidecar and AST-owned Hermes hook as the
data plane. Add three domain-separated local control surfaces: delivery policy,
runtime integrity, and the existing event channel. Make rendering return an
explicit card/native disposition, and keep process-manager/recovery mutations
behind exact configuration plus verified ownership evidence.

**Tech Stack:** Python 3.9+, dataclasses, argparse, aiohttp, HMAC-SHA256,
pytest/pytest-asyncio, Feishu CardKit JSON 2.0, transient systemd units, Docker
Compose.

## Global Constraints

- Work only in V4.1.0 worktrees created from the committed design baseline.
- Preserve the original checkout and all unrelated user changes.
- Never hand-edit an installed Hermes source file.
- Hook decisions fail open to Hermes native output; source/process mutations
  fail closed.
- Event, policy, and runtime proofs use different signing domains.
- `auto` never enters system systemd or invokes privilege escalation.
- No automatic Hermes Gateway restart.
- Do not log, test-fixture, document, or publish raw chat ids, transport secrets,
  local paths, private message text, or recovery fingerprints.
- Run loopback aiohttp suites outside the filesystem sandbox when required by
  the environment.
- Release version is exactly `4.1.0`.

## Release Stop Conditions

Do not tag or close any issue if one of these remains:

- a native-policy query failure can swallow Hermes output;
- a direct command/notice path bypasses the native policy;
- any table row or later prose disappears in default compact mode;
- an oversized terminal can be acknowledged as card-delivered;
- integrity safe mode can mutate without strict Git/manifest/source evidence;
- a repair or monitor restarts Gateway automatically;
- `auto` can reach system systemd or any path writes `/etc`;
- health/CLI/logs disclose identifiers, secrets, paths, or raw fingerprints;
- exact merge tests, public-install provenance, or real Feishu acceptance are
  missing.

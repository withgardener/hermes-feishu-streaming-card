# V4.3.0 Integration Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the pure capability selector and exact Hermes plugin package metadata that every V4.3.0 runtime, patcher, and installer decision will consume.

**Architecture:** Keep compatibility selection in a side-effect-free module with closed capability vocabularies and a canonical, domain-separated fingerprint. Publish one opt-in Hermes entry point whose import is inert; its `register(ctx)` facade delegates lazily so this milestone does not change installed Hermes behavior before the runtime bridge exists.

**Tech Stack:** Python 3.9+, dataclasses, `enum.StrEnum`-compatible string enum pattern, `hashlib`, canonical JSON, setuptools entry points, pytest.

## Global Constraints

- `integration.py` must not read files, import Hermes, send HTTP, or mutate process state.
- Supported modes are exactly `native-hooks`, `hybrid`, and `legacy-patch`; an unsupported decision has `mode=None` and `supported=False`.
- `native-hooks` is selected only when every required official capability is verified.
- Current Hermes v0.20 / `v2026.8.3` selects `hybrid` only with the exact four reviewed native capabilities and all 17 Hybrid patch groups, including `subagent_parent_identity`; `native-hooks` still requires all 13 native capabilities, including native `subagent_lifecycle`.
- Legacy selection requires the complete Legacy patch group set; version strings never substitute for capability evidence.
- Capability names and patch group names are closed vocabularies; unknown names raise `ValueError`.
- Fingerprints are stable across input ordering and change when any capability fact changes.
- Plugin key, group, module, distribution, and package version are exact public identities.
- Importing `hermes_feishu_card.hermes_plugin` performs no network or filesystem mutation and imports no Hermes private module.
- This milestone does not enable the plugin, patch Hermes, or restart Gateway.

- [ ] **Step 3: Implement the exact public model**

  In `hermes_feishu_card/integration.py`, add this complete pure implementation:

  ```python
  from __future__ import annotations

  from dataclasses import dataclass
  from enum import Enum
  import hashlib
  import json
  from typing import Iterable


  class IntegrationMode(str, Enum):
      NATIVE_HOOKS = "native-hooks"
      HYBRID = "hybrid"
      LEGACY_PATCH = "legacy-patch"


  @dataclass(frozen=True)
  class NativeHookCapabilities:
      available: frozenset[str]

      @classmethod
      def from_names(cls, names: Iterable[str]) -> "NativeHookCapabilities":
          values = frozenset(str(name) for name in names)
          unknown = values - KNOWN_NATIVE_CAPABILITIES
          if unknown:
              raise ValueError(
                  "unknown native capabilities: " + ", ".join(sorted(unknown))
              )
          return cls(values)


  @dataclass(frozen=True)
  class PatchCapabilities:
      available: frozenset[str]

      @classmethod
      def from_names(cls, names: Iterable[str]) -> "PatchCapabilities":
          values = frozenset(str(name) for name in names)
          unknown = values - KNOWN_PATCH_GROUPS
          if unknown:
              raise ValueError(
                  "unknown patch groups: " + ", ".join(sorted(unknown))
              )
          return cls(values)


  @dataclass(frozen=True)
  class IntegrationDecision:
      supported: bool
      mode: IntegrationMode | None
      reason: str
      required_native_capabilities: frozenset[str]
      required_patch_groups: frozenset[str]
      fingerprint: str


  def capability_fingerprint(
      native: NativeHookCapabilities,
      patches: PatchCapabilities,
  ) -> str:
      payload = {
          "domain": "hfc-integration-capabilities-v1",
          "native": sorted(native.available),
          "patches": sorted(patches.available),
      }
      canonical = json.dumps(
          payload,
          ensure_ascii=True,
          sort_keys=True,
          separators=(",", ":"),
      ).encode("utf-8")
      return "sha256:" + hashlib.sha256(canonical).hexdigest()


  def select_integration_mode(
      native: NativeHookCapabilities,
      patches: PatchCapabilities,
  ) -> IntegrationDecision:
      fingerprint = capability_fingerprint(native, patches)
      if NATIVE_REQUIRED_CAPABILITIES <= native.available:
          return IntegrationDecision(
              supported=True,
              mode=IntegrationMode.NATIVE_HOOKS,
              reason="all required official capabilities are verified",
              required_native_capabilities=NATIVE_REQUIRED_CAPABILITIES,
              required_patch_groups=frozenset(),
              fingerprint=fingerprint,
          )
      if (
          HYBRID_REQUIRED_NATIVE_CAPABILITIES <= native.available
          and HYBRID_REQUIRED_PATCH_GROUPS <= patches.available
      ):
          return IntegrationDecision(
              supported=True,
              mode=IntegrationMode.HYBRID,
              reason="official lifecycle and all required hybrid patch groups are verified",
              required_native_capabilities=HYBRID_REQUIRED_NATIVE_CAPABILITIES,
              required_patch_groups=HYBRID_REQUIRED_PATCH_GROUPS,
              fingerprint=fingerprint,
          )
      if LEGACY_REQUIRED_PATCH_GROUPS <= patches.available:
          return IntegrationDecision(
              supported=True,
              mode=IntegrationMode.LEGACY_PATCH,
              reason="complete legacy patch groups are verified",
              required_native_capabilities=frozenset(),
              required_patch_groups=LEGACY_REQUIRED_PATCH_GROUPS,
              fingerprint=fingerprint,
          )
      missing_native = sorted(
          HYBRID_REQUIRED_NATIVE_CAPABILITIES - native.available
      )
      missing_hybrid = sorted(HYBRID_REQUIRED_PATCH_GROUPS - patches.available)
      missing_legacy = sorted(LEGACY_REQUIRED_PATCH_GROUPS - patches.available)
      return IntegrationDecision(
          supported=False,
          mode=None,
          reason=(
              "missing verified integration capabilities: "
              f"native={missing_native}; hybrid={missing_hybrid}; "
              f"legacy={missing_legacy}"
          ),
          required_native_capabilities=HYBRID_REQUIRED_NATIVE_CAPABILITIES,
          required_patch_groups=HYBRID_REQUIRED_PATCH_GROUPS,
          fingerprint=fingerprint,
      )
  ```

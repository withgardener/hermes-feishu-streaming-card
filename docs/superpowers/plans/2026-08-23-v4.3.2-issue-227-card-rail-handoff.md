# V4.3.2 Issue #227 Card Rail Handoff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix Issue #227 by keeping schema 2.0 streaming messages and legacy interaction messages on stable, separate card rails, then publish verified release v4.3.2.

**Architecture:** `FEISHU_MESSAGE_IDS_KEY` remains bound to the existing schema 2.0 streaming card. Each pending interaction is sent as an auxiliary legacy card and is closed through a legacy callback response; it is never promoted into the streaming PATCH slot. A Gateway dialect guard converts any accidental schema 2.0 callback card into a success toast.

**Tech Stack:** Python 3.9–3.12, aiohttp, pytest/pytest-asyncio, lark-oapi 1.6.8, GitHub Actions, setuptools wheel/sdist.

## Global Constraints

- Work only in branch `codex/issue-227-card-rail-handoff` and its isolated worktree.
- Do not modify `legacy/` or installed Hermes `gateway/run.py`.
- Do not change callback authentication, runtime admission, profile/chat/operator binding, expiry, or fail-open boundaries.
- Use TDD: every production behavior change must be preceded by a failing test and an observed RED result.
- A Feishu message must never change between legacy and schema 2.0 dialects.
- Do not record real identifiers, callback tokens, credentials, URLs, raw response bodies, or user answers.
- Target release is `4.3.2`; do not tag until the exact merge SHA passes the complete release gate.

class DialectAwareFeishuClient(FakeFeishuClient):
    def __init__(self):
        super().__init__()
        self.dialects = {}

    async def send_card(self, chat_id, card, thread_id=None, reply_to_message_id=None):
        message_id = await super().send_card(chat_id, card, thread_id, reply_to_message_id)

def _hfc_interaction_success_response(
    adapter: Any,
    card_data: dict[str, Any],
    toast_content: str,

    if card_data.get("schema") == "2.0" or "body" in card_data:
